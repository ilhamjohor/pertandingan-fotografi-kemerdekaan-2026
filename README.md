# Pertandingan Fotografi Kemerdekaan 2026

Anjuran Kelab Tabung Kebajikan Staf FELCRA Berhad Negeri Johor.

## Fungsi
- Login ahli menggunakan No. Staf
- Kata laluan awal ahli: `Felcra@2026`
- Upload foto pertandingan
- Like/unlike foto sendiri atau ahli lain
- Galeri disusun mengikut jumlah like
- Admin Dashboard dengan Top 5
- Admin boleh tambah ahli, reset kata laluan dan padam foto
